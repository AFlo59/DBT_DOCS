# 📚 Roadmap - Documentation DBT

> Documentation technique complète de DBT (Data Build Tool)  
> **Objectif** : Maîtriser DBT de la théorie à la pratique

---

## 🎯 Organisation de la Documentation

La documentation est organisée en **4 niveaux progressifs** :
1. **Concepts théoriques** - Comprendre les principes fondamentaux
2. **Configuration** - Paramétrer son environnement
3. **Éléments techniques** - Maîtriser chaque composant
4. **Bonnes pratiques** - Optimiser et industrialiser
